# 双 ESP32 拆分工程 —— 架构与接线说明

按商业计划书「双 ESP32 协同分板架构」将原单板工程拆分为两个独立工程:
**数据板(sketch_sep8b,采集+执行)** 与 **联网板(sketch_sep24a,通信+上云)**,板间 UART 互联。

原单板完整版已备份为: `C:\Users\Lenovo\Desktop\ESP32项目文件\单板完整版备份_sketch_sep8b.ino`

## 一、两个工程的位置

| 板 | 工程文件 | 职责 |
|---|---|---|
| 数据板 | `D:\Dan_Zi\Anduino IDE\Andriod project\esp32 data\sketch_sep8b\sketch_sep8b.ino` | 采集 7 路传感器 + 控制执行器 |
| 联网板 | `D:\Dan_Zi\Anduino IDE\Andriod project\esp32 network\sketch_sep24a\sketch_sep24a.ino` | WiFi/MQTT 上云 + BLE 蓝牙 + 转发指令 |

## 二、架构总览

```
┌─────────────────────────────┐        UART        ┌─────────────────────────────┐
│   数据板  sketch_sep8b       │ ◄────────────────► │   联网板  sketch_sep24a      │
│  (ESP32-WROOM-32D)          │  每5秒数据帧↑       │  (ESP32-WROOM-32D)          │
│                             │  控制帧↓            │                             │
│  · DHT22   温湿度            │                     │  · UART 收数据帧             │
│  · HX711   称重              │   {"temp":"22.8",   │  · WiFi + MQTT 上云(巴法云)  │
│  · YF-S201 水流              │    "hum":"61.0",   │  · BLE 蓝牙(ESP32-Monitor)   │
│  · GY-906  红外体温           │    ...}\n           │  · 收指令→转发数据板执行      │
│  · MQ-2    气体              │                     │                             │
│  · TEMT6000 光照             │   LED:on\n ◄────── │                             │
│  · LED 执行器(ledPin=4)      │                     │  · 云端/手机 on/off 指令      │
└─────────────────────────────┘                     └─────────────────────────────┘
      ↑ 传感器全部接在这块板                              ↑ 只接 USB/WiFi 天线,不接传感器
```

- **数据流**: 数据板每 5 秒采 7 项数据 → UART JSON 帧 → 联网板 → MQTT 上云 + BLE 通知
- **控制流**: 小程序/Web → MQTT 或 BLE 发 `on/off` → 联网板 → UART `LED:on/off` → 数据板执行
- **小程序无需改动**: 设备名、UUID、7 字段 JSON 格式全部保持不变

## 三、板间接线(4 根线)

| 联网板 sketch_sep24a | 接法 | 数据板 sketch_sep8b |
|---|---|---|
| GPIO16 (RX2) | ← | GPIO19 (TX1) |
| GPIO17 (TX2) | → | GPIO23 (RX1) |
| GND | 连接 | GND |
| (5V 可选) | — | VIN (可共用供电) |

> 两块板各插 USB 供电即可,但 **GND 必须共地**,否则 UART 收不到数据。

## 五、UART 协议

- 波特率: **115200**, 8N1
- 数据帧(数据板→联网板,每 5 秒,以 `\n` 结尾):
  `{"temp":"22.8","hum":"61.0","weight":"21.9","flow":"0.00","irtemp":"24.4","gas":"311","lux":"172"}`
- 控制帧(联网板→数据板,以 `\n` 结尾):
  `LED:on` / `LED:off`(可扩展 `PUMP:on`、`FAN:on` 等执行器)

## 六、烧录步骤

1. Arduino IDE 分别打开两个工程
2. 开发板选择 **ESP32 Dev Module**,端口选择对应 COM 口(拔插 USB 确认哪块板是哪个口)
3. 分别点击「上传」
   - 若报 `Failed to connect`,按住板上 **BOOT** 键再点上传,出现 Connecting 时松手
4. 上传顺序无所谓,两块板可同时上电

## 七、验证

1. **数据板**: 打开串口监视器(115200),应每 5 秒打印一条 `发送: {...}` JSON
2. **联网板**: 打开串口监视器(115200),应打印 WiFi 连接、MQTT 已连接、每 5 秒一条 `转发上云: {...}`
3. **云端**: 微信小程序远程 WiFi 模式应正常显示数据
4. **蓝牙**: 小程序切「蓝牙直连」,手机靠近联网板,应能搜到 `ESP32-Monitor` 并读到数据
5. **控制**: 小程序点 LED 开关 → 联网板转发 → 数据板 GPIO4 上的 LED 亮/灭

## 八、注意

- 联网板 WiFi 配置在文件头 `ssid` / `password`,按需修改(支持 2.4G,不支持 5G 和中文 SSID)
- 称重标定值已更新:`hxOffset = 13066`、`hxScale = 410.9`(2026-09-25 空载+210g 标定,单位克,误差 ±1.5g);换传感器/改安装后需重新标定:空载 raw0、带载 raw1,hxScale=(raw1-raw0)/克数
- 联网板已开启省电优化:CPU 80MHz、WiFi 省电模式+13dBm、BLE 广播间隔 600ms;BLE 断开后自动恢复广播
- 若日后加 RFID(PN532)、继电器、风扇驱动,接在**数据板**上,并在控制帧里扩展指令即可
