# ESP32 智能养殖多传感器远程监控系统（双 ESP32 + 巴法云 MQTT + 微信小程序）

基于 **2× ESP32-WROOM-32D**（Arduino 框架）的**双板异构架构**：**数据板**负责 7 路传感器采集与执行器控制，**联网板**负责 WiFi/MQTT 上云与 BLE 蓝牙直连，两板通过 **UART 协议**互联。手机端微信小程序支持「远程 WiFi」/「蓝牙直连」双通道切换，数据统一汇总写入云开发数据库。

> **当前进度（2026-09-25）：双板拆分 + 双通道全部真机验证通过。**

---

## 一、系统架构

```
┌──────────────────────────┐        UART        ┌──────────────────────────┐
│   数据板 (sketch_sep8b)  │ ◄─────────────────► │   联网板 (sketch_sep24a) │
│  ESP32-WROOM-32D         │  每5秒数据帧↑       │  ESP32-WROOM-32D         │
│                          │  控制帧↓            │                          │
│  · DHT22 温湿度          │                     │  · UART 收数据帧          │
│  · HX711 称重(±1.5g)     │   {"temp":"25.1",   │  · WiFi + MQTT 上云      │
│  · YF-S201 水流          │    "hum":"52.7",    │  · BLE 蓝牙直连手机       │
│  · GY-906 红外体温        │    ...}\n           │  · 收指令→UART 转发执行   │
│  · MQ-2 气体 / 光照       │                     │                          │
│  · LED 执行器(GPIO4)     │   LED:on\n ◄─────── │  · 云端/手机 on/off 指令  │
└──────────────────────────┘                     └──────────────────────────┘
      │ 传感器全部接在这块板                           │ 只接 USB/天线,不接传感器
      │                                                        │
      │                    MQTT(TCP 9501)        WSS(9504)      │
      │            ┌──────────────┐   ◄───────────────►  ┌──────────────┐
      └────────────► │   巴法云     │                     │  微信小程序    │
                     │  bemfa.com   │                     │  LED控制+显示  │
                     └──────────────┘                     └──────┬───────┘
                                                           wx.cloud 数据库
                                                       sensor_records(每分钟平均)
```

- **数据流**：数据板每 5 秒采 7 字段 JSON → UART → 联网板 → MQTT 发布 `temhum` + BLE 特征值
- **控制流**：小程序/Web → MQTT(`led002`)或 BLE(控制特征)发 `on/off` → 联网板 → UART `LED:on/off` → 数据板执行
- **数据库**：小程序双通道下都累加平均，每 60 秒写入云开发 `sensor_records`

## 二、引脚分配（双板）

### 数据板（esp32 data\sketch_sep8b）
| 模块 | 引脚 | 供电 | 说明 |
|---|---|---|---|
| 板间 UART TX / RX | **GPIO19 / GPIO23** | — | Serial1 @115200，发数据帧/收控制帧 |
| 被控 LED（执行器） | GPIO4 | GPIO 驱动 | 接收 `LED:on/off` |
| DHT22 温湿度 | GPIO5 | 3.3V/5V | 需 4.7k~10k 上拉 |
| HX711 称重 DT / SCK | GPIO16 / GPIO17 | 5V | 标定 hxOffset=13066 / hxScale=410.9（克） |
| YF-S201 水流 | GPIO18 | 5V | 中断脉冲计数 |
| GY-906 红外测温 SDA/SCL | GPIO21 / GPIO22 | **3.3V** | I2C 0x5A |
| MQ-2 气体 AO | GPIO34 | 5V | ADC1，需预热 |
| TEMT6000 光照 AO | GPIO32 | 3.3V/5V | ADC1 |
| 电源灯 / 错误灯 | 25 / 26,27,14 | GPIO 驱动 | 26/27/14 显示传感器错误码 |

### 联网板（esp32 network\sketch_sep24a）
| 模块 | 引脚 | 说明 |
|---|---|---|
| 板间 UART RX / TX | **GPIO16 / GPIO17** | Serial2 @115200，收数据帧/发控制帧 |
| 状态灯 | 无 | 4 个灯全部在数据板(25 电源+故障闪烁, 26/27/14 错误码);联网板状态看串口/小程序 |
| — | — | **不接任何传感器** |

> ⚠️ **接线注意**：数据板 GPIO19→联网板 GPIO16；联网板 GPIO17→数据板 GPIO23；**两板 GND 必须共地**。传感器/板子供电建议分开（尤其 MQ-2 加热丝 ~200mA），避免共用弱电源触发欠压重启。
> ⚠️ **WiFi 限制**：ESP32 只支持 **2.4GHz**，不支持 5G；**中文 SSID 可能连不上**，建议用英文数字名。

## 三、板间 UART 协议

- 波特率 **115200**，8N1，`\n` 结尾
- 数据帧（数据板→联网板，每 5 秒）：`{"temp":"25.1","hum":"52.7","weight":"0.0","flow":"0.00","irtemp":"25.3","gas":"291","lux":"0"}`
- 控制帧（联网板→数据板）：`LED:on` / `LED:off`（可扩展 `PUMP:on`、`FAN:on` 等）

## 四、LED 状态 / 故障码

### 联网板（网络状态）
联网板**不装状态灯**(4 个灯全部在数据板)。判断联网状态:
- 串口日志:出现 `WiFi 已连接` → `MQTT 已连接` → 每 5 秒 `转发上云: {...}` = 正常
- 小程序:顶部显示「● 已连接云端」+ 数值实时刷新 = 端到端正常

### 数据板（传感器错误码，26/27/14 亮灭组合，●=1 ○=0；多故障时显示编号最小者）
| 码 | 26 | 27 | 14 | 含义 | 排查方向 |
|---|---|---|---|---|---|
| 1 | ● | ○ | ○ | HX711 称重超时 | 检查 GPIO16/17、5V 供电 |
| 2 | ○ | ● | ○ | GY-906 红外未找到 | 检查 GPIO21/22、3.3V、共地 |
| 3 | ● | ● | ○ | DHT22 读取失败 | 检查 GPIO5 接线/上拉 |
| 4 | ○ | ○ | ● | MQ-2 读 0（预热 5 分钟后才检测，防误报） | 检查 GPIO34 接 AO、5V 供电 |

> 有故障时**电源灯(25) 以 1Hz 闪烁告警**；正常时电源灯常亮。错误检测不再高频轮询 HX711/DHT22，称重超时按"5 秒未成功读取"判断，避免干扰读数。

## 五、数据上报格式（每 5 秒，主题 `temhum`）

```json
{"temp":"25.1","hum":"52.7","weight":"0.0","flow":"0.00","irtemp":"25.3","gas":"291","lux":"0"}
```

| 字段 | 含义 | 单位 |
|---|---|---|
| temp / hum | DHT22 温度 / 湿度 | ℃ / % |
| weight | HX711 重量 | **g**（标定 hxScale=410.9） |
| flow | YF-S201 流速 | L/min（频率÷7.5） |
| irtemp | GY-906 红外测温 | ℃ |
| gas | MQ-2 烟雾 ADC | 0~4095 |
| lux | TEMT6000 光照 ADC | 0~4095 |

## 六、数据库平均记录（小程序端）

- 小程序收到每条上报后**累加**（按当前激活通道，不重复累加）；
- 每 **60 秒**计算平均值写入云开发集合 **`sensor_records`**；
- 字段：7 项平均值 + `time` + `timeStr`；页面显示数据库最近 5 条；
- 建议在云开发控制台给 `sensor_records` 建 **`time` 降序索引**（消除全量查询告警）。

## 七、双通道说明

| 通道 | 路径 | 特点 |
|---|---|---|
| 远程 WiFi | 数据板→UART→联网板→MQTT→巴法云→小程序 | 不限距离（需 2.4G WiFi） |
| 蓝牙直连 | 联网板 BLE→手机小程序 | 10 米内，无网可用 |

- BLE 设备名 `ESP32-Monitor`；数据特征 `6E400002...`（Read+Notify）、控制特征 `6E400003...`（Write）；UUID 与小程序一致
- **断开后自动恢复广播**（已修复"连一次后搜不到"问题）
- **省电优化**（联网板已启用）：CPU 80MHz、WiFi 省电模式+发射功率 13dBm、BLE 广播间隔 600ms

## 八、依赖库（Arduino 库管理器）

数据板：**DHT sensor library**、**HX711 Arduino Library**、**Adafruit MLX90614 Library**
联网板：**PubSubClient**、**BLEDevice（ESP32 内置）**
小程序：`utils/mqtt.min.js`（MQTT.js v4.2.1）

## 十、烧录与运行

1. **联网板**：打开 `esp32 network\sketch_sep24a` → **分区方案选 `Huge APP (3MB No OTA/1MB SPIFFS)`**（WiFi+BLE 固件 1.65MB 超默认分区）→ 开发板 `ESP32 Dev Module` → 选对 COM 口上传
2. **数据板**：打开 `esp32 data\sketch_sep8b` → 默认分区即可 → 上传
3. 串口验证：数据板每 5 秒 `发送: {...}`；联网板打印 `WiFi 已连接`→`MQTT 已连接`→`转发上云: {...}`
4. 小程序导入 `miniprogram/`，勾选"不校验合法域名"，编译运行
5. 若上传报 `Failed to connect`：按住 BOOT 键再点上传，出现 Connecting 时松手
